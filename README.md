# Seraphin Native Flow

Production-ready multilingual website for Seraphin Boutique Spa in Yerevan. The opening experience uses the authentic Seraphin logo and a scroll-controlled photographic portal into the real treatment room, followed by the complete EN/HY/RU service catalogue, ritual finder, current AMD prices, real venue imagery, contact actions and direct Emly booking.

## Production link

`https://seraphin-native-flow.rezaiixhossein.chatgpt.site/`

## Local commands

- `npm run dev` — local development server
- `npm run build` — type-check and production build
- `npm run check` — lint, build and desktop/mobile Playwright checks

Source data and launch caveats are recorded in `DATA_SOURCES.md`.
