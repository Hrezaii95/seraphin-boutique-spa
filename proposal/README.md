# Seraphin website proposal

Two print-ready, single-page commercial proposals issued by **REZAEI LLC** for the Seraphin Boutique Spa website project.

- `seraphin-proposal-en.html` — native English edition
- `seraphin-proposal-hy.html` — native Eastern Armenian edition

## Printing

Open either file in Chrome or Edge and select **Print → Save as PDF** with:

- Paper: A4
- Margins: None
- Scale: 100%
- Background graphics: On
- Headers and footers: Off

The logo is loaded from `../public/images/seraphin-logo.jpg`. Keep the `proposal/` and `public/` directories in their current relative positions when previewing locally.
